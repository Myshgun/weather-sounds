# Weather Sounds App

Приложение для воспроизведения звуков природы с красивым визуальным интерфейсом, собранное с помощью Webpack.

## 🎯 Функциональность

- **Воспроизведение звуков природы**: лето, дождь, зима
- **Управление воспроизведением**: пауза/продолжение при повторном нажатии
- **Переключение между звуками**: автоматическая остановка предыдущего трека
- **Регулировка громкости**: плавное изменение уровня звука
- **Динамические фоны**: смена фонового изображения в зависимости от выбранного звука
- **Визуальная обратная связь**: смена иконок при воспроизведении/паузе

## 🛠 Технологии

- **Webpack 5** - сборка проекта
- **HTML5** - структура приложения
- **CSS3** - стилизация и адаптивный дизайн
- **Vanilla JavaScript** - логика приложения
- **Web Audio API** - работа со звуком
- **CSS Grid/Flexbox** - верстка

## 🚀 Установка и запуск

### Предварительные требования

- Node.js (версия 14 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run build:dev
```

### Сборка для production

```bash
npm run build
```

Собранные файлы появятся в папке `dist/` (автоматически создается)

### Просмотр собранной версии

```bash
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`

## 🎮 Использование

1. **Выбор звука**: Нажмите на одну из трех карточек:

   - ☀️ Лето (летние звуки)
   - 🌧️ Дождь (звуки дождя)
   - ❄️ Зима (зимние звуки)

2. **Управление воспроизведением**:

   - Первое нажатие - запуск звука
   - Повторное нажатие на ту же карточку - пауза
   - Нажатие на другую карточку - остановка текущего и запуск нового звука

3. **Регулировка громкости**:
   - Используйте ползунок внизу для изменения громкости

## ⚙️ Особенности реализации

### Webpack конфигурация

- **Раздельные конфиги** для development и production
- **Обработка ресурсов**: изображения, шрифты, аудио
- **HTML Webpack Plugin** для автоматической генерации HTML
- **Hot Module Replacement** в dev-режиме
- **Автоматическая очистка** папки `dist` при каждой сборке

### Аудио система

- Используется Fetch API для загрузки аудиофайлов
- Blob URLs для эффективного управления памятью
- Автоматическая пауза предыдущего трека при выборе нового
- Сохранение позиции воспроизведения при паузе

### Интерфейс

- Адаптивный дизайн
- Шрифт Roboto для лучшей читаемости
- Плавные переходы между состояниями
- Визуальные индикаторы активного звука

## 🎨 Кастомизация

### Добавление новых звуков

1. Добавьте аудиофайл в `public/assets/sounds/`
2. Добавьте иконку в `public/assets/icons/`
3. Добавьте фоновое изображение в `public/assets/images/`
4. Обновите константы в `src/index.js`:

```javascript
const ICON = {
  // ... существующие иконки
  newSound: "./assets/icons/new-icon.svg",
};

const BACKGROUND = {
  // ... существующие фоны
  newSound: "url('./assets/images/new-bg.jpg')",
};
```
